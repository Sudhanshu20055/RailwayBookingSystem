# Railway Ticket Booking System

A Java-based Railway Ticket Booking System developed using Core Java and Object-Oriented Programming (OOP) principles. The system provides essential railway booking functionalities such as user registration, train search, ticket booking, cancellation, PNR management, seat allocation, and fare calculation.

## Features

- User Registration and Login
- Train Search
- Ticket Booking
- Ticket Cancellation
- PNR Generation and Management
- Automatic Seat Allocation
- Fare Calculation
- Passenger Management
- Input Validation
- Exception Handling

## Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)
- Collections Framework
- HashMap
- ArrayList
- Regular Expressions (Regex)
- Exception Handling
